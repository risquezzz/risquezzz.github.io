Case study — IMETAL, C.A.

Industrial pump and rotating-equipment repair company in El Tigre, Venezuela. B2B, oil and gas. I measured its visibility across ChatGPT, Gemini and Perplexity using 30 unbranded buying questions, each run in a fresh chat with memory disabled.

What the data showed

  1. Visibility collapses at the top of the funnel. The brand appears in two thirds of transactional answers and in barely a quarter of comparative ones. It is chosen when the buyer already knows what to buy.
  2. Six conceptual prompts produced zero mentions. Questions like “how is a major overhaul of a centrifugal pump performed?” returned no supplier at all — across 18 observations in three engines. The space is not held by a competitor; it is empty.
  3. Mention is not citation. 40 answers named the brand, but only 22 cited its domain with a URL. The rest were reconstructed from model memory, which is far more fragile.
  4. The engines disagreed on the same day. ChatGPT 60.0%, Perplexity 40.0%, Gemini 33.3% on identical prompts. Auditing a single assistant is not a measurement.

Limitations stated openly: single-day snapshot, three of four relevant surfaces (Google AI Overviews pending), undisclosed model versions, and Perplexity does not expose source URLs through its interface.

Case study 2 — Technical SEO audit

An external audit of the same client's site: crawling, structured data, performance and content architecture. The GEO baseline measured the symptom; this explains the cause.

HTML pages 1 Anchor navigation only. Zero internal URLs.
Image weight 7.4MB 35 JPEG files, no lazy loading, no responsive sizes.
Structured data 0 The JSON-LD block is invalid: JavaScript was pasted inside it.
  1. The Schema cannot be parsed. A security script sits inside the application/ld+json block, so the LocalBusiness markup is invisible to every crawler.
  2. There is nothing to cite. One page and 1,172 words for five service lines. That is the root cause of the zero mentions in the GEO baseline.
  3. Two hosts serve the same content. www and non-www both return 200 with no redirect.

Method

Every number on this page can be traced back to a row in a workbook.

01

Design prompts by intent

30 buying questions in four intents, written as a real buyer would ask. No brand name in any prompt.

02

Isolate each observation

One fresh chat per prompt, memory off, no context carryover. Otherwise prompt 30 inherits the previous 29.

03

Capture evidence, not impressions

Full response, timestamp, engine, cited URLs and competitors detected — stored per row.

04

Classify by hand where judgement is needed

All 40 mentions were reviewed individually. Appearing in a neutral table does not count as a recommendation.

05

Report limits before results

Sample size, single pass, undisclosed models. A metric without its limitation is marketing.
